## KRYPT v1.6.2

This release improves saving, backup recovery, editor behavior, and study tracking, and updates the desktop runtime.

### Changes

- Saves can recover after temporary directory or permission failures. Opening KRYPT again focuses the existing app, preventing conflicting workspace saves.
- Changing the data folder preserves recovery backups and snapshots and commits the change only after copying succeeds. Failed changes leave the original folder active.
- Backup imports validate nested data more thoroughly, and the progress chart safely displays imported review counters.
- Subject names such as `toString` work correctly.
- Resized images keep their layout and editing controls after saving and reopening a note. Ctrl/Cmd+U works for underline.
- Select note text to create a flashcard using the Make Flashcard action.
- Dialogs contain keyboard focus, restore focus when closed, and support Escape where cancellation is safe. An unresponsive app offers explicit recovery choices when closing.
- Study streaks and review history use local calendar dates. Timers track elapsed time, pause correctly, and start a full session when restarted after completion.
- Updated Electron to 44.5.1 and electron-builder to 26.15.3; removed unused dependencies and obsolete backup source from packages.
- Before publication, 15 logic/persistence tests and 9 Electron interface tests passed. The updated dependency audit reports zero vulnerabilities.

### Windows downloads

- **KRYPT.Setup.1.6.2.exe** — installer with installation-folder selection and shortcuts.
- **KRYPT.1.6.2.exe** — portable executable.

Use Settings to create a workspace JSON backup. Historical study-day keys are preserved; new activity is recorded using local calendar dates.
