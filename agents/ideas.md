# KRYPT — Improvement Ideas

These are remaining proposals, ordered by priority. Completed items are removed from this list and recorded in `agents/progress.md`.

1. **Improve keyboard and screen-reader access.** Make dialogs, context menus, editor controls, and Kanban movement usable without a mouse; add labels and visible focus states throughout.
2. **Add due-date views and reminders.** Bring upcoming tasks, tests, and flashcard reviews into one view, with optional local reminders.
3. **Add tags and search across subjects.** Search notes, tasks, and flashcards together, with filters for type, subject, and tag.
4. **Offer more flashcard scheduling controls.** Let users tune review intervals and see why a card is due, while keeping sensible defaults.
5. **Make study trends more flexible.** Let users set goals and inspect review, streak, and completion trends over custom date ranges.
6. **Link related study material.** Allow notes to reference other notes, flashcards, and tasks.
7. **Improve first-use guidance.** Add a short onboarding flow and an optional sample workspace.
8. **Expand localization and date/time preferences.** English and Croatian are available; add more languages and let users choose date format and 12- or 24-hour clock.
9. **Document releases for each platform.** Record Windows and macOS build requirements, signing steps, and a repeatable release checklist.
10. **Show app version and changes.** Add an About screen and a concise changelog.
11. **Expand editor checks.** Add a browser-level check for rich-text paste, formatting, image insertion, note switching, and persistence across a restart.
12. **Export individual notes.** Add TXT, HTML, and DOCX export actions; the current export creates a full-workspace JSON backup.
